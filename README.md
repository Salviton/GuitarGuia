# 🎸 Duende — Academia de Guitarra Flamenca

> *"Deja de dar palos de ciego. Aquí tienes el camino."*

Página web personal para el aprendizaje estructurado de la guitarra flamenca. Diseñada para guitarristas de nivel intermedio que quieren avanzar con orden, claridad y dirección.

---

## ¿Qué incluye?

### 📋 Currículum por niveles
Un camino de aprendizaje dividido en 5 niveles, desde los cimientos hasta el arte propio. Cada nivel tiene contenidos concretos y una duración orientativa para que sepas siempre dónde estás y hacia dónde vas.

### 🤚 Biblioteca de técnicas
7 técnicas flamencas explicadas paso a paso con ejercicios prácticos:
- Rasgueo
- Picado
- Trémolo
- Alzapúa
- Golpe en tapa
- Ligados
- Rasgueo abanico

### 🎵 Acordes interactivos
Diagramas visuales de los acordes flamencos esenciales organizados por tonalidad (por arriba y por medio), con digitación completa al hacer clic. Incluye la cadencia andaluza explicada visualmente.

### 📺 Videoteca
Vídeos seleccionados de YouTube organizados por categoría (técnica, palos, maestros, teoría) con filtros interactivos.

### 📅 Plan semanal
Rutina de estudio de 50 minutos diarios estructurada para nivel intermedio.

---

## Cómo usar

Esta es una web estática de un solo archivo HTML. No necesita instalación ni servidor.

1. Clona o descarga el repositorio
2. Abre `index.html` en cualquier navegador
3. O visita la web en vivo en: `https://tuusuario.github.io`

---

## Tecnologías

- HTML5 semántico
- CSS3 con variables y animaciones
- JavaScript vanilla
- Fuentes: Playfair Display, Libre Baskerville, Space Mono (Google Fonts)
- Sin frameworks, sin dependencias externas
